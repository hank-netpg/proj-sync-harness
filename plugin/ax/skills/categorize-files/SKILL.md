# 파일 재분류 (판단 보정)

`slack_download.sh` 는 **확장자**만으로 카테고리를 정합니다. 이 스킬은 확장자가 모호하거나 99_기타로 떨어진 파일을 **내용·파일명 맥락**으로 올바른 카테고리로 옮깁니다.

## 절차
1. `.proj-sync/config.json` 의 `categories` 를 읽어 카테고리 체계를 파악한다.
2. `slack-files/99_기타/` 와 분류가 의심스러운 파일을 나열한다.
3. 각 파일을 파일명·(가능하면) 내용으로 판단:
   - 예: `*.pdf` 가 "제안요청서/RFP" 면 `05_실적_기타` → `01_제안요청서_RFP` 로 이동
   - 예: 이미지가 실제로는 견적 캡처면 `06_이미지_캡처` 유지
4. `git mv` (또는 `mv`)로 이동하고, **이동 사유를 사용자에게 표로 보고**.
5. `FILE_INVENTORY.csv` 의 `category`·`saved_path` 컬럼도 함께 갱신.

## 원칙
- 확신 없으면 옮기지 말고 사용자에게 묻는다(추측 금지).
- FILEID 접두사(`F0B...__`)는 보존한다(원본 추적).
- 이동 후 반드시 변경 내역을 표로 제시.
