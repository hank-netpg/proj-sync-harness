**원칙 — 사람이 쓴 메시지는 삭제·수정하지 않습니다.** 남의 말을 지우거나 고치는 것은 대화 기록을 위조하는 일입니다. 이 커맨드가 지울 수 있는 것은 **이 봇이 직접 게시한 메시지뿐**이며, 사람·타 앱 봇의 메시지는 조회 단계에서 차단됩니다. 남의 메시지에 정정이 필요하면 작성자에게 알리거나 정정 메시지를 덧붙이세요.

봇이 게시한 Slack 메시지를 회수합니다. **삭제는 되돌릴 수 없고 첨부 파일 공유까지 함께 사라지므로** 2단계로 동작합니다.

- `--yes` 없이 실행 → 대상 메시지의 작성자·시각·본문·첨부·리액션·답글 수를 출력하고 **지우지 않습니다**
- `--yes` 를 붙이면 → 위 사전조사를 출력한 뒤 실제로 삭제합니다

```!
bash ${CLAUDE_PLUGIN_ROOT}/scripts/slack_delete.sh $ARGUMENTS
```

**회수 전 사용자에게 확인할 것** — 아래 중 하나라도 해당하면 삭제하지 말고 정정 메시지를 덧붙이는 편이 낫습니다.

- 상대가 이미 회신했는가 (스레드 답글·리액션)
- 그 메시지가 상대가 요청한 자료를 담고 있는가
- 제3자에게 전달·인용됐는가

스크립트가 차단하는 경우 — ① 사람이 쓴 메시지 ② 다른 앱 봇이 쓴 메시지 ③ 봇 소유를 확인하지 못한 경우(`auth.test` 실패) ④ 스레드 부모(답글이 고아가 됨).

삭제 후 대체 메시지가 필요하면 `slack_post.sh`(텍스트) 또는 `slack_upload.sh`(파일 첨부)로 다시 올리고, 스레드 위치를 유지하려면 `--thread <부모 ts>` 를 붙이세요.
